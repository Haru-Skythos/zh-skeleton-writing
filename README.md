# zh-skeleton-writing

中文论文写作技能，装在 Claude Code、ZCode 等支持 SKILL.md 的 agent 上运用。它把"先搭论证骨架、再填充成句"做成工作区强制步骤，用来消除中文论文的 AI 味。

**解决的问题**：LLM 写中文论文常见先结论后证据、数据后缀"这表明"、括号冒号展开。根因在论证结构：模型跳过写作前规划，直接采样下一个词。规则依据三篇《声学学报》论文 41 段 170 句逐句标注，比如范文 11,902 字全角冒号 0 次、口语动词 0 次；长句打包率为每句 1.2 到 4 个逻辑节点。

**七步流程**：
1. 材料进场：任务、数据表、数字白名单、红线落文件
2. 断言清单：一条断言对应一段
3. 四层骨架卡：节论证链 / 段落 / 逻辑节点 / 打包成句
4. 卡片过审：查预期问题、背景独立节点、结算句前提、结论节点位置
5. 隔离填充：写手只看当前卡
6. 机械门禁：三个 Python 脚本检查
7. 脱架定稿：通读顺衔接，不改信息

**门禁四类**：数字全来自白名单；无自造词与英文直译句式；无解释性括号；无冒号展开与口语动词。不通过退回对应层。

**安装**：复制本目录到 skills 目录，Claude Code 对应 `~/.claude/skills/`，ZCode 对应 `~/.zcode/skills/`，重启会话。门禁脚本需 Python 3，无其他依赖。

**使用**：对话里说"用 zh-skeleton-writing 写 X 节"，或给 subagent 派任务时贴 SKILL.md 路径。材料按 SKILL.md 第 1 步格式提供。

**目录**：
```
SKILL.md       主流程（七步）与规则索引
references/    四份细则：卡片规范、骨架库、风格规则、自检清单
scripts/       三个门禁脚本：数字白名单、禁用词、括号边界
evals/         测试用例
```

**测试**：在 GLM-5.3、GLM-5.3-Flash、deepseek-flash 上做功能测试，含无技能对照组。带技能运行全过机械门禁与结构审查；对照组会漏解释性括号、冒号展开、口语动词、段首裸主张。记录见规则文档迭代说明。

**边界**：方法依据三篇语音方向《声学学报》论文，其他学科未验证；这是写作规范，不是 AI 检测器；门禁脚本为启发式，数字白名单需每个任务单独提供。
