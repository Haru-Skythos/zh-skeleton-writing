# 四层骨架卡规范

## 层级总览

```
L0 节论证链   断言清单 + 各段结算句 ↔ 下一段前提（链条）
L1 段落      段落功能 / 读者预期问题 / 结算句
L2 节点序列   逻辑节点（槽簇）+ 节点间关系（句群关系）
L3 打包决策   节点 → 句子的分配 + 挂接方式
────────────────────────────────────
句子 = L3 的产物，不直接规划
```

## L0 节论证链

两部分：

**断言清单**（每条断言 = 一段）：本节要证明的中心主张，一条一行。断言必须是可检验的判断，"介绍频率映射消融"不是断言，"往返对照把低频损失定位在输入表示、排除训练归因"才是。

**链条.md**：把每段的结算句和下一段的段落功能并排抄下来：

```
P1 结算句：均匀映射在进入网络前已丢失低频细节，损失属于输入表示。
P2 段落功能：既然输入侧有损，量化该损失对最终指标的影响 →（接得上）
P2 结算句：……
```

接不上的位置就是链条断点，改 P1 的结算句或 P2 的功能，不能靠填充时加过渡句糊过去。

## L1 段落卡（每段一张卡的头部）

三个字段：

**段落功能**：写这段补哪个论证缺口，不是这段讲什么。
- ✗ 这段介绍频率映射消融
- ✓ 在任何训练结果之前，用无可学参数的往返实验把低频损失定位在输入特征本身，防止后文差距被误读为训练造成的

**读者预期问题**：具体到读者会问的那句话。
- ✗ 读者想知道结果
- ✓ 读者会问：均匀映射在进入网络之前到底丢了多少低频信息？

**结算句**：本段最后一句的判断，同时是下一段的前提。必须是判断不是描述。
- ✗ 本节分析了频率映射的影响
- ✓ 均匀映射在进入网络之前已丢失低频幅度细节，该损失属于输入表示，不能归因于训练

## L2 节点序列

把段落功能拆成逻辑节点。**节点 = 一个完整的最小论证动作**（一个主张、一个读数、一个让步、一个机制），每个节点带 2–4 个槽位（逻辑位，不写具体内容）。

节点间关系用句群关系词表（封闭集，不许发明新关系名）：

| 关系 | 含义 | 信号词（范文实测） |
|---|---|---|
| 并列 | 同层并列的两个方面 | 一方面…一方面…；分号 |
| 承接 | 前后相接的下一步 | 于是；随后；其中 |
| 递进 | 在前者基础上升级 | 进一步地；甚至 |
| 转折 | 反向修正 | 然而；但是；尽管如此 |
| 因果 | 前因后果 | 由于；因此；为此 |
| 条件 | 设定生效条件 | 在…条件下；若 |
| 解说 | 展开、具体化、总括 | 具体而言；其中；综合来看 |
| 目的 | 动作的目的 | 为了；以期 |
| 对照 | 两对象横向比 | 相比之下；与之相比 |

节点写法：

```
N1 [收益A]  槽位：[改动, 作用频段, 收益机制]        ← 并列 → N2
N2 [收益B]  槽位：[保留对象, 收益机制]              ← 转折 → N3
N3 [代价]   槽位：[代价来源, 放大效应]              ← 因果 → N4
N4 [补偿]   槽位：[补偿手段, 抵消机制]              ← 解说 → N5
N5 [净结果] 槽位：[效果侧, 成本侧, 同时成立]
```

背景信息（训练设置、实验条件、输入格式）必须各自占独立节点，不许压进别的节点的槽里——被压缩的背景在填充时一定溢出成解释性括号。

**节点排序规则（信息流）**：条件/设置/操作/观察节点在前，读数节点居中，结论/结算节点在段尾。中文的信息流是"条件 → 操作 → 读数 → 结论"，结论用"表明/可见/因此"在句末兑现。**禁止把结论节点排在段首**——[结论]+[支持] 是英文段落写法，是 AI 味最深的来源。例外：结论章的首句、摘要的"为此"句。

## L3 打包决策

把节点分配给句子，并写明挂接方式。分配表格式：

```
句1 = N1 + N2 + N3 + N4   挂接：收益A一方面…一方面…，但代价，用补偿手段
句2 = N5                  单句结算
```

挂接方式三种（长句的生长机制，全部来自范文）：

1. **挂接顺序固定**：目的 → 手段 → 机制 → 代价 → 补偿 → 净收益。主干只放改动或判断，新信息按这个顺序一次挂一个。
2. **分号并列**：两个对等的读数、两个对称的分支，用分号并排。
3. **成对义务**：改了一个部件，必须交代对称件或逆操作（编码器后 3 块对应解码器前 3 块）。

**量化锚点**（范文实测，超限就要检查是不是在堆砌）：

- 每段：一个预期问题、3–9 个节点、产出 3–5 句（中位 4）；
- 每句：装 1–4 个节点（中位约 2），**装 4 个以上必须有挂接结构或分号并列，禁止往句尾堆修饰语**——那是句子变长但信息没变多的反例；
- 每句槽位上限 6；
- 0 个节点被拆进两个句子（实测从未出现，出现即打包错误）。

## 完整示例

### 示例 1：方法章模块说明（B 篇 2.3，一句话装下完整权衡）

```
【P3｜2.3 模块说明】
段落功能：论证加大卷积核与控制网络规模这对矛盾如何被分组卷积化解。
读者预期问题：加大卷积核长度收益明显，网络规模怎么办？
结算句：该设计在保持增强效果的同时控制了参数量和运算量。
节点：
  N1 [收益A：长时卷积]   槽位：[改动, 时间跨度, 适应对象]     ← 并列
  N2 [收益B：细节提取]   槽位：[保留对象]                    ← 转折
  N3 [代价：规模扩大]    槽位：[代价来源, 放大路径]           ← 因果
  N4 [补偿：分组卷积]    槽位：[手段, 抵消机制]               ← 解说
  N5 [净结果]            槽位：[效果侧, 成本侧]
打包：
  句1 = N1+N2+N3+N4  挂接：一方面…一方面…，但…，用分组卷积补偿
  句2 = N5           单句结算
```

### 示例 2：实验读数段（某消融分析节的第一段）

```
【P1｜4.2.1 开头】
段落功能：在任何训练结果之前，用无可学参数的往返实验把低频分辨率损失定位在
输入特征本身，防止后文差距被误读为训练或优化造成的。
读者预期问题：4.1 主表里本文方法 LSD_Low 为 7.63 dB，这个领先有多少来自
逐频点输入映射？均匀映射在进网络之前丢了多少低频信息？
结算句：均匀映射在进入网络之前就已丢失低频幅度细节，该损失属于输入表示，
不能归因于训练。
节点：
  N1 [过渡：主结果→第一组消融]  槽位：[上一节结论, 本节第一问]     ← 承接
  N2 [对照设置]                 槽位：[对照对象, 操作, 频带, 训练条件] ← 承接
  N3 [对照读数]                 槽位：[指标, 均匀读数, 对称读数, 差距] ← 因果
  N4 [排除训练归因]             槽位：[可学参数, 归属判断]          ← 解说
  N5 [未答问题]                 槽位：[已确立, 待查]               ← 承接（出段）
打包：
  句1 = N1            过渡句
  句2 = N2            设置句（训练条件独立成句，不进括号）
  句3 = N3            读数句：判断在前，括号补 delta
  句4 = N4            归因句
  句5 = N5            结算句
证据：N3 ← 8.47/0.000 dB；N4 ← 往返无可学参数。
```

## 给 subagent 的任务模板

派卡任务（只规划不写正文）时，把本文件 + `skeleton-library.md` 原样贴进 prompt，并加五条要求：每段一个中心主张；预期问题必须具体；槽位写逻辑位不写数值；结算句必须是能当下段前提的判断；思考全程用中文。填充任务（第二阶段）把单张卡 JSON 传回，要求"逐槽填充，不得增删槽位"。
