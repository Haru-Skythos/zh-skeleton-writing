# 自检清单（写完一节逐项过，每项附证据）

任何一项打不上勾，回到对应的层修（文末有对照表）。这份清单不是勾完就算完——括号问题、直译问题、段碎问题的根因都在卡片层，文字层改只能治标。

## 一、结构

- [ ] 每段只有一个中心主张？出现两个就拆段。
- [ ] 每段有可检验主张 + 可追溯支撑？
- [ ] 段首是**起句**（承接上段缺口/条件场景/指表指图/背景事实），判断在句末或段末兑现，而不是裸主张先行？（结论章、摘要"为此"句除外）
- [ ] 有没有英文 topic sentence（"X 的另一个变量是 Y"式标签开场）？
- [ ] 结算句是判断，且成为下一段的前提？
- [ ] 段落长度随证据密度变化，是 8–15 行的完整论证单元？
- [ ] 有没有被拆碎的论证单元？

## 二、句子

- [ ] 主干只放改动或判断，新信息逐个挂接？
- [ ] 每个技术断言后面有机制小句（从而/是由于/表明/进而）？
- [ ] 有让步？让步精确到失效模式？
- [ ] 没有只有结论没有机制的句子？
- [ ] 没有删掉也不影响论证的句子？（有就删）
- [ ] 每句装的节点数 ≤4，超过的用了挂接结构或分号并列？
- [ ] 信息流是否"条件/操作/读数在前，结论在句末兑现"？（[结论]+[支持] 是英文写法）
- [ ] 有没有"证据句 + 判断句 + '这表明'句"三连碎句？论证链应整合进长句。
- [ ] 是不是每组读数都缀了一句小结论？（全段一次裁决，留给结算句）

## 三、括号

- [ ] 括号里只有术语定义、数值补值、文献编号？
- [ ] 没有解释性括号（时间、条件、位置、输入格式、方法说明）？
- [ ] 括号内容能变独立分句的都拆出去了？

## 四、数字

- [ ] 每个数字写清指标名、对比对象、单位、测量条件、方向？
- [ ] 结果段是"对比对在前 → 定性词 → 括号补值"？
- [ ] 正文没堆绝对值（绝对值在表里）？
- [ ] 方向反直觉的读数有交代？
- [ ] 数字全部来自白名单，无增删改？

## 五、术语

- [ ] 缩写首现有中文全称 + 英文括号，二次出现只用缩写？
- [ ] 同一概念全篇一种说法，技术名词没换同义词？
- [ ] 没有用"它"指代技术对象？
- [ ] 英文技术词已汉化（Stage 1 → 第一阶段，30k → 30,000）？

## 六、用词

- [ ] "证明了"真的做了验证？没统计检验没用"显著"？
- [ ] 推测性归因用了"可能是"？
- [ ] 结论带限定条件？
- [ ] 没有自造词、英文直译句式？
- [ ] 没有口语动词（做/跑/搞/弄/给出）？训练流程是"进行训练/引入对抗训练"，图表是"如表 N 所示"而非"给出了"？
- [ ] 指代技术对象全部用"其/该X"，无"它"？组件名后缀（模块/单元/支路…）全篇唯一？

## 七、格式

- [ ] 数字与单位之间有空格？中英文之间有空格？
- [ ] 负号用减号？图表引用完整（"表 2 的第 1, 2 行"）？
- [ ] 正文有没有"X：Y"冒号展开？（全角冒号一律拆成完整句：其中/即/分别为/分号列举；卡片记号不许进正文）

## 八、最后一问

- [ ] 把全文逐句译回英文，有没有和英文论文句式逐字对应的句子？有就是直译，用中文重新组织。

## 症状 → 根因层

| 打不上勾的项 | 回哪层修 |
|---|---|
| 结构类（碎段、结算句断裂） | L1 段落卡 / L0 链条 |
| 段首裸主张、topic sentence、逐条小结论 | L2 节点排序（结论节点移到段尾）+ L3 打包（论证链合并进长句） |
| 机制缺失、让步缺失 | L2 节点不全，补节点 |
| 括号类 | L2 缺背景节点或 L3 打包没分配，回卡 |
| 数字类 | 第 1 步材料，回 brief 核对 |
| 直译、术语、格式 | 第 5 步填充的语言层，逐句改写 |
