# 风格细则（填充时对照，门禁脚本兜底）

## 术语

1. 缩写首次出现：中文全称 + 英文括号，"短时客观可懂度 (STOI)"；之后只用缩写。
2. 同一概念全篇只有一种说法。技术名词不许换同义词——计算量就是计算量，重复 12 次也不换，重复是精确性的一部分。
3. 指代技术对象用"其"（且用作所有格），不用"它"。
4. 英文技术词汉化：Stage 1 → 第一阶段；30k → 30,000。保留英文的只有指标缩写和方法名（PESQ、STOI、ERB、ONNX 等）。

## 禁用词与替换

**自造词**（在项目里被用成术语、范文里找不到的词）：

| 禁用 | 替换 |
|---|---|
| 口径 | 指标定义 / 测量结果 / 测量条件 / 阶段 |
| 兑现 | 显现 / 出现 / 生效 |
| 锚定 | 定位 / 确定 / 扣住 |
| 回撞 | 承接 |
| 闭环 | 完整流程 / 前后接上 |
| 落盘 | 写入文件 / 保存 |
| 赋能 | 删除 |
| 维度（作"方面"讲时） | 方面 / 指标 |

**口语比喻**：收车（→训练结束）、糊化（→相邻谐波落入同一子带）、崩至（→降至）、拖垮（→受损）、猜回（→恢复）、贴线/贴边（→接近上限）、跑稳（→稳定运行）。

**英文直译句式**（不是词的问题，是句子照搬英文结构。判断法：逐字译回英文，像英文论文就是直译）：

| 直译式 | 中文写法 |
|---|---|
| 唯一变量是输入精度 | 只改变输入精度 / 除输入精度外其余条件不变 |
| 推进到第一阶段 | 进入第一阶段 / 转到第一阶段 |
| 需要单独排序 | 要单独考察 / 分别比较 |
| 测的是输入表示的信息瓶颈 | 反映的是输入表示的信息损失 |
| 被用于…… | 用于…… / 借助…… |
| 进行了……的分析 | 分析了…… |
| 在……方面 | 直接说具体对象 |

## 括号边界

范文的括号只有三种：术语定义（中文全称 + 英文缩写）、数值补值（正文给方向，括号给值，"下降较多 (1.8 dB, 0.123)"）、文献编号 [12]。

其余一切（补充说明、限定条件、时间步数、输入格式）写进正文。判断法：把括号里的内容拿出来，能变成独立分句就必须拆出去。括号多 = 骨架没排够，回卡片补节点，不是改括号。

## 信息流顺序（中文与英文的分界线，最重要的一条）

RL 训练把英文写作技巧烧进了模型：**先给结论，再垫支持**（[结论]+[支持]、PEEL 段式、topic sentence）。这不是中文的写法，是 AI 味最深的一个来源。范文实测（41 段 170 句）：段首句几乎全是叙事性起点——背景、定义、条件、指表指图、承接上段、让步；结论型段首 41 段里只有 1 处（结论章的"提出了……"）。结论标记（表明/可见/因此/从而）27 次出现在句中句末，8 次在句首——**判断是在条件、操作、读数之后兑现的**。

规则：

1. **信息流固定：条件/场景/操作/观察 → 变化/读数 → 归因/结论。**结论用"表明/可见/因此/从而"在句末或段末兑现，不许抢先。
   - ✗ "映射方式的影响没有随训练消失。表 4 中第 1, 2 行……"（裸主张先行，证据垫后）
   - ✓ "对比表 4 的第 1, 2 行，两行只改动输入映射一项，LSD_Low 由 7.63 dB 升至 8.47 dB，可见映射方式的影响没有随训练消失。"
2. **禁止裸主张段首句**（无锚点的短判断句开段）。段首第一句是起句：承接上一段的缺口、给条件场景、指表指图、或陈述背景事实。例外：结论章首句、摘要的"为此"句。
3. **禁止英文 topic sentence**（"X 的另一个变量是 Y"式的主语-表语开场）。这种句子的功能是给段落贴标签，中文段落靠第一句的叙事动作带出主题。
4. **一个论证链优先装进一个长句**，不要拆成"证据句 + 判断句 + '这表明'句"三连。范文把"对比→发现→机制→结论"用"通过对比……发现……表明……从而……"整合在一句里流动；拆成碎句再逐条裁决，是英文 PEEL 的痕迹。
5. **不要逐条小结论。**一组读数配一句"这表明/这说明"，是 PEEL 的 Link 句病。机制和判断挂在读数句内或留给段末结算句，全段一次裁决。
6. **正文零冒号展开。**"总起句：具体展开"（如"训练分两个阶段：第一阶段只做纯重建"）是卡片记号渗入正文的痕迹，也是绕过句子组织的又一个出口，与解释性括号同族。范文实测：全角冒号 11,902 字零次；半角冒号 0.67 次/千字且全部用于编号列举（"两个关键局限性： 一方面…"）。展开的信息用完整句子挂接——"其中""即""分别为""当…时"，并列内容用分号。
   - ✗ 训练分两个阶段：第一阶段只做纯重建，共 30,000 步
   - ✓ 训练分两个阶段，其中第一阶段只做纯重建，共 30,000 步


## 动词语域与名词引用（书面正式度，语料实测）

范文 11,902 字中口语动词**全部零次**：做、跑、搞、弄、看、拿出、给出、拿到、执行。规则：

1. **口语动词禁用**：做（做出/做法除外）、跑（训练）、搞、弄。流程动作用"进行+N"（进行训练/测试/卷积/建模/迭代，范文 32 次）；瞬时动作用直接动词（分析了、对比、验证、估计）；处置用"将 X 替换为 Y""将 X 作为 Y 进行…"；依据用"基于 X"。
2. **"给出"换写法**：范文 0 次。"表 N 给出了…"→"如表 N 所示""实验结果表明"。
3. **组件进入用"引入"**，不用"加入"（范文 引入 6 次 vs 加入 2 次）；信号与噪声的物理混合可保留"加入"。
4. **设置句句式**："X 为 Y"（训练数据集为 90000 条）、"共 N 步"、"由…组成"、"分别来自/分别为"。
5. **名词引用**：主语是物——该方法/该网络/该模块/所提方法（范文 该X 7 次、所提 6 次）；"本文"只做归属句（本文提出了/本文选取）；指代一律用"其"（32 次），"它"仅 1 次且是"它们"，视同禁用；组件后缀从词表取且全篇唯一：模型/网络/方法/算法/模块/单元/支路/分支/子带/层/策略。
6. 语域示例（训练阶段描述）：
   - ✗ 其中第一阶段只做纯重建，共 30,000 步，第二阶段加入对抗训练，训练至 75,000 步
   - ✓ 训练分两个阶段，第一阶段仅进行纯重建，共 30,000 步；第二阶段引入对抗训练，训练至 75,000 步。

## 语气

1. 长句为主：一句挂 2–4 个信息点，多层逗号分句、分号并列；短句只做节奏调剂。不要短句堆叠。
2. 主语是物不是人：该方法/该网络/所提方法做主语，动词用具体动作（提升、抑制、保留、降低、验证）。"本文"只出现在归属句。
3. 程度副词分层且对应可查数字：显著 / 明显 / 较为 / 基本一致。没做统计检验不用"显著"；推测性归因用"可能"。
4. 逻辑词固定在结构位：然而 / 为此 / 其中 / 另外 / 具体而言 / 总体上 / 综合来看。
5. 段落是 8–15 行的完整论证单元，不碎段；段落长度随证据密度变化，不追求匀称。
6. 方法描述挂骨架："以……为基础，通过……实现……，从而……"。

## 格式

- 数字与单位之间有空格：90 dB；
- 中文与英文之间有空格：复杂 UNet；
- 负号用减号不用连字符；
- 图表引用完整：写"表 2 的第 1, 2 行"或"图 4(f)"，不写裸"表""图"；
- 归纳衔接允许："总体上""综合来看"在有数据支撑时是范文常规手法，禁的是空洞拔高（奠定基础/具有重要意义/展现出潜力）。
